# Oyabun



Quick and dirty render engine for graphics test projects.



## Compiling



Install Visual Studio 2026.

Install the Windows 11 SDK (10.0.26100.0)



Clone this repository:

```bash
git clone https://github.com/Adrikikicp2/Oyabun.git
git lfs fetch
git submodule update --init --recursive
```



Open `Oyabun.slnx` and then hit Build.



If you want to debug, hit Run.

# Disclaimer

This project is not a fully-fledged game engine.
It's designed for users to implement a game engine on top of it, by abstracting the complex overhead of modern graphics APIs
like DirectX 12, Vulkan and similar.
